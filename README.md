# landing-page-project

this is my project submission for task 1, I chose a coffee themed
website because coffee is one of my all-time favourite beverages and where I
come from, we are well renowned for our coffee. I have tried to make my
code as clear and as legible as possible. Hope you like it

**Live site:** https://b-mwangi.github.io/landing-page-project/

## Features

- **Navigation menu** with logo and links to Home, About, Services and Contact
- **Mobile hamburger menu** that opens and closes on small screens
- **Hero section** with a headline, subtext and a call-to-action button
- **About section** with the company story over a full-width background photo
- **Services section** with three cards: sourcing, processing and distribution
- **Stats section** with numbers that count up when scrolled into view
- **Testimonials section** with three customer testimonials
- **Footer** with contact details, quick links and social media links
- **Smooth scrolling** between sections
- **Scroll animations** using ScrollReveal
- **Fully responsive** layout for mobile, tablet and desktop

## Built with

- HTML5
- CSS3 (Flexbox, Grid, media queries, CSS variables)
- JavaScript
